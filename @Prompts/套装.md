 **Bundle / Kit 模块**

---

### ① Bundle Setup

👉 套装的开关 & 类型

| Field (English) | 必填度  | 中文说明                                         |
| --------------- | ---- | -------------------------------------------- |
| Enable Bundle   | \*必选 | 是否为套装商品（Yes / No，依赖 Basic Info Product Type） |
| Bundle Type     | \*必选 | Fixed Set（固定套装）/ Configurable（可选组合）          |
| Parent SKU      | \*必填 | 套装 SKU（继承 Basic Info，不再重复维护）                 |

---

### ② Component Items

👉 定义套装包含哪些子件

| Field (English)      | 必填度  | 中文说明                   |
| -------------------- | ---- | ---------------------- |
| Child SKU            | \*必填 | 套装包含的子 SKU             |
| Quantity per Bundle  | \*必填 | 子件数量                   |
| Substitution Allowed | 可选   | 是否允许替代品                |
| Substitute SKUs      | 条件必填 | 替代 SKU 列表              |
| Inheritance Rule     | \*必选 | 套装属性继承：重量/尺寸/条码（继承/覆盖） |

---

### ③ Inventory Handling

👉 套装与子件的库存逻辑

| Field (English)        | 必填度  | 中文说明                       |
| ---------------------- | ---- | -------------------------- |
| Stock Deduction Rule   | \*必选 | 销售套装时，库存是否按子件扣减            |
| Inventory Display Mode | \*必选 | 套装库存展示方式：独立库存 / 动态计算（基于子件） |
| Replenishment Rule     | 可选   | 套装库存低时是否自动组装               |

---

### ④ Warehouse Handling

👉 WMS 场景下的套装管理

| Field (English)      | 必填度  | 中文说明                                           |
| -------------------- | ---- | ---------------------------------------------- |
| Kit Mode             | \*必选 | Virtual（虚拟套装，仅 OMS 层）/ Physical（实物套装，占 WMS 库存） |
| Disassembly Allowed  | 可选   | 是否允许仓库拆解套装                                     |
| Assembly Instruction | 可选   | 组装说明（文本/附件）                                    |
| Picking Strategy     | 可选   | 出库方式：拣整套 / 拣子件组套                               |

### ⑤ Audit & Logs

| Field (English)   | 必填度  | 中文说明     |
| ----------------- | ---- | -------- |
