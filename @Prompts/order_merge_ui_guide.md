## 📝 完整创建流程示例

### 步骤 1: 打开创建对话框
```
点击 "Create Rule" 按钮
```

### 步骤 2: 填写基本信息
```
Name: 同一客户订单自动合并
Description: 1小时内同一客户的订单自动合并到SO级别
```

### 步骤 3: 设置过滤条件（可选）
```
Order Source: Shopify
Filter: Financial Status = Paid
```

### 步骤 4: 选择动作类型
```
在 Actions 区域，点击 "Select action" 下拉框
选择 "Order Merge" > "Merge Orders"
```

### 步骤 5: 配置合并节点
```
点击 "SO Level" 卡片
✓ 标记出现，卡片高亮
```

### 步骤 6: 设置合并条件
```
✓ Same Customer      (已开启)
✓ Same Shipping Address  (已开启)
○ Same Warehouse     (关闭，因为是SO级别)
○ Same Shipping Method  (关闭)
```

### 步骤 7: 配置时间窗口
```
✓ Enable time window
   60 minutes
```

### 步骤 8: 设置合并策略
```
Max Orders: 5
Max Items: (留空)
Primary Order Selection: Earliest Order
```

### 步骤 9: 选择触发模式
```
◉ Immediate
```

### 步骤 10: 通知设置
```
✓ Send notification when orders are merged
```

### 步骤 11: 查看预览
```
预览横幅显示:
🔗 Merge at Sales Order (SO) Level
   [Same Customer] [Same Address]
```

### 步骤 12: 保存规则
```
点击 "Save" 按钮
规则创建成功！
```

## 💡 使用技巧

### 1. 快速配置
- 使用默认值快速创建规则
- 后续可以编辑优化

### 2. 节点选择建议
- **SO Level**: 适合订单量大、需要快速处理
- **DN Level**: 适合需要精确物流控制

### 3. 时间窗口设置
- **短时间 (30-60分钟)**: 高频订单场景
- **长时间 (2-4小时)**: 低频订单场景

### 4. 触发模式选择
- **Immediate**: 订单量稳定时使用
- **Scheduled**: 订单高峰期使用
- **Manual**: 高价值订单审核

---

## ⚠️ 注意事项

1. **必填字段**: 带 * 的字段必须填写
2. **节点选择**: 必须先选择节点才能看到完整配置
3. **条件逻辑**: 所有启用的条件都必须满足（AND逻辑）
4. **时间窗口**: 关闭时间窗口意味着无时间限制
5. **预览更新**: 预览横幅会实时反映您的配置
