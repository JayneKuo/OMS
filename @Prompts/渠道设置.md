

# 📦 渠道上架（Channel & Listing）模块 — 功能分区与字段

---

### ① 渠道选择（Channel Scope）

👉 确定商品要铺货到哪些渠道/店铺/站点，以及同步模式。

| 字段                 | 必填度  | 说明                                             |
| ------------------ | ---- | ---------------------------------------------- |
| Available Channels | \*必选 | 系统从集成中心读取可用渠道（Amazon, eBay, Shopify, Walmart…） |
| Enable Channel     | \*必选 | 开关：是否将该商品铺货到该渠道                                |
| Account / Store    | 条件必填 | 若渠道有多店铺/账号时需选择                                 |
| Marketplace / Site | 条件必填 | 如 Amazon US/CA/UK, eBay UK…                    |
| Sync Mode          | \*必选 | 统一模式（One-to-Many）/ 定制模式（Per-Channel）           |
| Fulfillment Type   | 可选   | FBM / FBA / WFS / 自营仓                          |

---

### ② 列表内容（Listing Content）

👉 默认继承 Basic Info，必要时 per-channel 覆盖。

| 字段                     | 必填度  | 说明                                        |
| ---------------------- | ---- | ----------------------------------------- |
| Title                  | \*必填 | 默认继承 Product Name，可覆盖                     |
| Description            | 可选   | 默认继承 Basic Info，可覆盖                       |
| Bullet Points          | 可选   | 默认继承 Basic Info，可覆盖                       |
| Images                 | \*必填 | 默认继承主图/附图，可调整顺序/覆盖                        |
| Category / Browse Node | \*必填 | 默认继承 Category → 渠道类目映射，可覆盖                |
| Variation Theme        | 条件必填 | 多变体商品时按渠道映射（如 Amazon: SizeName/ColorName） |

---

### ③ 价格与促销（Pricing）

👉 唯一强差异化维度，支持统一价与渠道价。

| 字段                      | 必填度  | 说明                                 |
| ----------------------- | ---- | ---------------------------------- |
| Base Price              | \*必填 | 继承统一售价                             |
| Channel Price           | 可选   | 定制模式下可维护不同售价                       |
| MSRP / Compare-at Price | 可选   | 对比价/市场参考价                          |
| Sale Price              | 可选   | 促销价，支持 Start/End 时间                |
| Tax Class               | 条件必填 | 部分渠道必填，可继承或覆盖                      |
| Pricing Rule            | 可选   | 规则引擎，如「Walmart = Base Price\*1.05」 |

---

### ④ 库存与可售策略（Inventory & Availability）

👉 定义不同渠道的库存逻辑与可售规则。

| 字段                       | 必填度  | 说明                         |
| ------------------------ | ---- | -------------------------- |
| Inventory Source         | \*必选 | 统一库存池 / FBA / WFS / 指定仓库   |
| Available Qty            | 只读   | 从 OMS/WMS 拉取，可加安全库存 Buffer |
| Safety Stock Buffer      | 可选   | 每渠道可配置的安全库存预留量             |
| Min Purchase Qty         | 可选   | 最小购买量                      |
| Max Purchase Qty         | 可选   | 最大购买量                      |
| Out-of-Stock Policy      | \*必选 | 缺货时：禁止下单 / 允许预售            |
| Preorder Settings        | 条件必填 | 预售商品：开始/结束时间、预计发货日         |
| Handling Time / Lag Time | 条件必填 | 渠道要求的发货 SLA                |

---

### ⑤ 配送与退货（Shipping & Returns）

👉 使用全局模板，减少重复配置。

| 字段                         | 必填度  | 说明                        |
| -------------------------- | ---- | ------------------------- |
| Shipping Template          | \*必填 | 默认继承全局模板，可 per-channel 覆盖 |
| Return Policy              | \*必填 | 默认继承全局模板，可 per-channel 覆盖 |
| Handling Fee               | 可选   | 部分渠道支持额外费用                |
| Weight/Dimensions Override | 可选   | 若渠道运费计算需要，可覆盖             |

---

### ⑥ 发布与同步（Publish & Sync）

👉 控制商品在各渠道的上架进度和结果。

| 字段                         | 必填度  | 说明                                                        |
| -------------------------- | ---- | --------------------------------------------------------- |
| Listing Status             | \*必选 | Draft / Scheduled / Publishing / Active / Failed / Paused |
| Sync Mode                  | \*必选 | 自动同步（随 Basic Info 更新）/ 手动同步（Push Now）                     |
| Schedule Publish/Unpublish | 可选   | 设置定时上架/下架                                                 |
| Progress                   | 系统生成 | 显示提交 → 渠道 → 完成/失败进度                                       |
| Sync Result                | 系统生成 | 成功/失败数量，错误详情                                              |
| Channel Identifier         | 系统生成 | 渠道回写 ID（ASIN, Item ID, Shopify Product ID 等）              |

---

### ⑦ 状态与总览（Dashboard Overview）

👉 运营人员一屏掌握所有渠道的上架进度。

| 字段                      | 必填度  | 说明                    |
| ----------------------- | ---- | --------------------- |
| Overview Table          | 系统生成 | SKU × 渠道 × 状态总览       |
| Filter                  | 可选   | 筛选渠道 / 店铺 / 状态        |
| Bulk Actions            | 可选   | 批量发布 / 撤销 / 应用模板      |
| Error Center            | 系统生成 | 集中显示失败 SKU 与错误原因      |
| Listing Readiness Score | 系统生成 | 上架健康度评分：必填/条码/图片/类目合规 |

---

✅ 页面交互推荐顺序：
**渠道选择 → 列表内容 → 价格与促销 → 库存策略 → 配送与退货 → 发布与同步 → 总览面板**
