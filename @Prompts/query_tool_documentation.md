# 多平台查询工具产品文档

## 1. 产品概述

多平台查询工具是一个集成化的数据查询平台，旨在帮助用户快速查询和管理跨平台的订单和商品数据。该工具提供了统一的查询界面，支持按不同维度筛选、展示和导出数据，提高了数据查询和管理的效率。

### 1.1 功能概述

- **多平台数据整合**：集成来自不同电商平台（如Amazon、Shopify、eBay、Walmart）的数据
- **多维度查询**：支持按客户、渠道、订单号等多个维度进行查询
- **订单查询**：查询渠道订单信息，包括订单状态、发货状态等
- **商品查询**：查询渠道商品信息，包括库存信息、同步规则等
- **详情查看**：支持查看订单详情、商品库存详情
- **数据导出**：支持将查询结果导出

## 2. 技术架构

### 2.1 前端架构

- **框架**：Vue 3 + TypeScript
- **UI组件库**：Element Plus
- **状态管理**：组合式API（Composition API）
- **路由**：Vue Router

## 3. 功能模块详解

### 3.1 查询表单模块

#### 3.1.1 基础查询字段
- **客户选择**: 必填字段，从预设的客户列表中选择
- **渠道选择**: 必填字段，根据所选客户动态加载对应的渠道列表
- **查询类型**: 选择 "渠道订单" 或 "渠道商品"

#### 3.1.2 订单查询字段
当查询类型为 "渠道订单" 时显示：
- **平台订单号**: 输入框，支持模糊查询
- **系统订单号**: 输入框，支持模糊查询
- **系统状态**: 下拉选择，包括：全部、已完成、处理中、待处理、异常
- **渠道发货状态**: 下拉选择，包括：全部、已发货、处理中、待发货、未发货、已送达、异常
- **订单日期**: 日期范围选择器

#### 3.1.3 商品查询字段
当查询类型为 "渠道商品" 时显示：
- **商品名称**: 输入框，支持模糊查询
- **SKU**: 输入框，支持查询SKU或渠道SKU

#### 3.1.4 操作按钮
- **查询按钮**: 触发查询，验证必填项后执行查询逻辑
- **重置按钮**: 清空所有查询条件，重置表单
- **导出按钮**: 导出当前查询结果数据

### 3.2 查询结果模块

#### 3.2.1 订单查询结果表格
当查询类型为 "渠道订单" 时显示，包含以下列：
- **客户名称**: 显示订单所属客户
- **渠道**: 显示订单所属渠道
- **店铺名称**: 显示订单所属店铺
- **渠道订单编号**: 显示渠道平台的订单编号
- **渠道发货状态**: 带标签显示订单在渠道平台的发货状态
- **渠道下单时间**: 格式化显示订单在渠道的创建时间
- **系统订单编号**: 如有关联系统订单则显示并可点击跳转，否则显示"-"
- **系统订单状态**: 带颜色标签显示系统中的订单状态，颜色对应不同状态
- **系统创建时间**: 格式化显示系统中的订单创建时间
- **操作**: 提供"查看明细"按钮，点击打开订单详情对话框

#### 3.2.2 商品查询结果表格
当查询类型为 "渠道商品" 时显示，包含以下列：
- **客户名称**: 显示商品所属客户
- **渠道**: 显示商品所属渠道
- **店铺名称**: 显示商品所属店铺
- **商品名称**: 显示商品名称，支持文本溢出提示
- **SKU**: 显示SKU，如有渠道SKU则小字显示在下方
- **Master SKU**: 显示Master SKU，如有则显示为链接样式，否则显示"-"
- **Master商品名称**: 显示Master商品名称，如无则显示"-"
- **渠道库存**: 右对齐显示渠道库存数量
- **WMS库存**: 右对齐显示WMS库存，鼠标悬停显示库存明细
  - 悬停弹出框显示各仓库库存：美国仓库、欧洲仓库、中国仓库、英国仓库
- **最近同步库存数**: 右对齐显示最近同步的库存数量，鼠标悬停显示同步规则
  - 悬停弹出框显示同步模式、同步比例/固定数量、上次同步时间等信息
  - 支持三种同步模式：按比例同步、固定数量、扣减同步
- **最近同步时间**: 格式化显示最近库存同步的时间

#### 3.2.3 分页控件
- 支持页码切换、页大小调整
- 提供总记录数显示
- 页大小选项：10/20/50/100条每页

### 3.3 订单详情对话框

订单详情对话框以弹窗形式展示订单的详细信息，包括：

#### 3.3.1 订单基本信息
- **订单号**: 显示渠道订单编号
- **订单状态**: 显示渠道订单状态
- **客户信息**: 显示客户名称
- **渠道信息**: 显示渠道名称
- **店铺信息**: 显示店铺名称
- **下单时间**: 显示订单创建时间

#### 3.3.2 订单商品列表
表格形式展示订单中的商品明细：
- **商品名称**: 显示商品名称
- **SKU**: 显示商品SKU
- **单价**: 显示商品单价，右对齐
- **数量**: 显示购买数量，居中对齐
- **小计**: 显示单项商品总价，右对齐
- **履约状态**: 带颜色标签显示商品的履约状态

#### 3.3.3 订单金额
- **订单总额**: 显示订单的总金额

## 4. 功能逻辑详解

### 4.1 数据获取逻辑

#### 4.1.1 客户数据加载
- 从`customers`数组获取客户列表
- 转换为下拉选项格式：`{ label: customer.name, value: customer.id }`

#### 4.1.2 渠道数据加载
- 基于选择的客户ID从`channelMap`获取对应的渠道列表
- 转换为下拉选项格式：`{ label: channel.name, value: channel.id }`
- 当客户选择变更时，清空渠道选择并重新加载渠道列表

#### 4.1.3 订单数据查询
当查询订单时，执行以下筛选逻辑：
1. 根据选择的客户筛选（通过客户名称匹配）
2. 根据选择的渠道筛选
3. 根据输入的渠道订单号筛选（包含匹配）
4. 根据输入的系统订单号筛选（包含匹配）
5. 根据选择的订单状态筛选
6. 根据选择的渠道状态筛选
7. 根据选择的日期范围筛选
8. 计算总记录数并进行分页处理

#### 4.1.4 商品数据查询
当查询商品时，执行以下筛选逻辑：
1. 根据选择的客户筛选（通过客户关联的渠道筛选）
2. 根据选择的渠道筛选
3. 根据输入的商品名称筛选（包含匹配）
4. 根据输入的SKU筛选（支持SKU和渠道SKU包含匹配）
5. 根据选择的商品状态筛选
6. 根据价格范围筛选（如有设置）
7. 计算总记录数并进行分页处理

### 4.2 展示逻辑

#### 4.2.1 条件渲染逻辑
- 基于`queryForm.type`值条件显示不同的查询字段和结果表格
- 订单类型显示订单查询字段和订单结果表格
- 商品类型显示商品查询字段和商品结果表格

#### 4.2.2 数据格式化逻辑
- **日期格式化**: 使用`formatDate`函数将时间戳转为本地日期时间格式
- **渠道名称获取**: 使用`getChannelName`函数根据渠道ID获取渠道名称
- **状态标签样式**: 使用`getStatusTagType`、`getProductStatusTagType`和`getFulfillmentStatusType`函数根据状态值设置不同颜色的标签

#### 4.2.3 条件显示逻辑
- **空值处理**: 对于可能不存在的字段，使用条件渲染，如无值则显示"-"
- **标签颜色**: 根据状态不同显示不同颜色的标签
- **库存悬停**: 对WMS库存和最近同步库存数添加悬停交互，显示详细信息

### 4.3 交互逻辑

#### 4.3.1 表单验证
- 客户和渠道为必填项，提交前验证
- 验证失败时显示警告信息

#### 4.3.2 分页处理
- 页码切换时更新`currentPage`，并触发重新查询
- 页大小改变时更新`pageSize`，并触发重新查询

#### 4.3.3 重置操作
- 清空所有查询条件字段
- 重置分页参数
- 隐藏结果区域

#### 4.3.4 刷新操作
- 使用当前查询条件重新执行查询
- 保持当前分页状态

#### 4.3.5 导出操作
- 验证必填项
- 模拟导出过程（实际应连接后端导出接口）

#### 4.3.6 查看订单详情
- 点击订单行的"查看明细"按钮时，打开订单详情对话框
- 将当前行的订单数据传递给对话框组件

#### 4.3.7 订单明细跳转
- 点击系统订单号可跳转到订单详情页面

### 4.4 数据同步机制

#### 4.4.1 库存同步规则
系统支持三种库存同步规则：

1. **按比例同步** (percent)
   - 将WMS库存按照指定百分比同步到渠道
   - 示例：80% 的库存同步到渠道

2. **固定数量** (fixed)
   - 固定数量的库存同步到渠道
   - 示例：固定100件库存同步到渠道

3. **扣减同步** (reduce)
   - 支持两种扣减方式：
     - 按百分比扣减：扣减指定百分比后同步
     - 按固定数量扣减：扣减指定数量后同步

#### 4.4.2 库存分布展示
- WMS库存鼠标悬停时显示各仓库库存分布
- 支持显示美国仓库、欧洲仓库、中国仓库、英国仓库等多仓库库存

## 5. 样式与用户体验

### 5.1 整体布局
- 页面采用卡片式布局，清晰分隔不同功能区域
- 顶部显示页面标题，中间为查询条件，底部为查询结果

### 5.2 表单样式
- 表单项采用三列布局，合理利用空间
- 必填项标记明显，提示用户必须输入
- 按钮居中放置，主要操作使用主色调

### 5.3 表格样式
- 表格采用边框样式，清晰区分各列
- 状态信息使用彩色标签直观展示
- 支持长文本溢出时显示提示
- 操作按钮放置在最右侧，便于操作

### 5.4 对话框样式
- 订单详情对话框居中显示，宽度适中
- 头部显示基本信息，主体显示商品列表
- 底部显示订单总金额
- 关闭时销毁内容，避免内存泄漏

### 5.5 响应式处理
- 表单项支持在小屏幕上自适应
- 表格滚动时固定右侧操作列
