
# 🏬 仓储与库存（Warehouse & Inventory）模块 — 功能分区与字段

---

### ① 库存管理（Inventory Settings）

👉 定义在仓内的可用性与补货基线

| 字段                | 必填度  | 说明                                           |
| ----------------- | ---- | -------------------------------------------- |
| Inventory Status  | \*必选 | Active / Blocked / Discontinued（影响是否允许收货/销售） |
| Default Warehouse | 条件必填 | 多仓商家需指定默认仓，用于首单入库/分配                         |
| Reorder Point     | 可选   | 低于此值触发补货提醒（供 OMS/WMS 使用）                     |
| Safety Stock      | 可选   | 安全库存阈值（可与渠道 Buffer 叠加）                       |
| Max Stock Level   | 可选   | 最大库存上限（超阈值预警）                                |

---

### ② 批次与效期（Batch & Expiration）

👉 食品/医药等需批次与效期管控的商品

| 字段                 | 必填度  | 说明                           |
| ------------------ | ---- | ---------------------------- |
| Batch Tracking     | \*必选 | 是否启用批次跟踪：Yes / No（入库需录入批次号）  |
| Expiration Control | 条件必填 | 是否启用效期管理：Yes / No            |
| Expiration Days    | 条件必填 | 保质天数（由生产/入库日 + N 天推算到期日）     |
| FEFO / FIFO Rule   | 条件必填 | 出库策略：FEFO（先到期先出）/ FIFO（先进先出） |
| Recall Flag        | 可选   | 是否支持批次召回/冻结标记                |

---

### ③ 序列号管理（Serial Number Management）

👉 3C/高价值商品逐台追踪

| 字段                   | 必填度  | 说明                             |
| -------------------- | ---- | ------------------------------ |
| Serial Tracking      | \*必选 | 是否启用序列号：Yes / No               |
| Serial Capture Point | 条件必填 | 记录时点：Inbound / Outbound / Both |
| Serial Format        | 可选   | 序列号格式（前缀、长度、校验位）               |

---

### ④ 存储与作业属性（Storage & Handling）

👉 指导库位分配、搬运与拣选

| 字段                  | 必填度  | 说明                         |
| ------------------- | ---- | -------------------------- |
| Temperature Control | 可选   | 常温/冷藏/冷冻；可录温区范围            |
| Hazmat Flag         | 可选   | 危险品标识（易燃/腐蚀/压缩气体…）         |
| Fragile Flag        | 可选   | 易碎品标识（影响搬运/周转箱）            |
| Mix Storable        | \*必选 | 与其他 SKU 是否可混放：Yes / No     |
| Stackable           | 可选   | 可堆叠：Yes/No；可衍生 Stack Limit |
| Default Zone        | 可选   | 默认库区（高位、地堆、冷库等）            |
| Putaway Strategy    | 可选   | 上架策略：固定库位/动态分配/最近空位        |
| Picking Strategy    | 可选   | 拣选策略：整箱优先/拆零优先/波次          |
| Replenishment Rule  | 可选   | 补货策略：Min–Max/阈值触发/定期补货     |

---

### ⑤ 包装与仓储计量（Packaging & Storage UOM）

👉 与 WMS 的物理层级与仓储计量对齐（结合 Basic Info 的 UOM/包装层级）

| 字段            | 必填度  | 说明                                 |
| ------------- | ---- | ---------------------------------- |
| Storage UOM   | \*必选 | 仓储计量单位：EA / Case / Pallet …        |
| Unit (EA)     | 固定=1 | 最小拣选单位                             |
| Inner Pack    | 可选   | 1 Inner = N EA；可填长宽高/重量（覆盖继承值）     |
| Master Carton | 可选   | 1 Carton = N EA / N Inner；可填长宽高/重量 |
| Palletization | 可选   | 每托盘装箱/装件数（用于收发货与库容规划）              |

> 说明：**尺寸/重量**的基础值由 Basic Info 维护；若仓储层面需不同，允许在本分区**覆盖**用于 WMS。

---

### ⑥ 条码与扫描（Barcodes for WMS）

👉 收货/拣选以条码为准，支持多层级条码

| 字段                       | 必填度  | 说明                          |
| ------------------------ | ---- | --------------------------- |
| Primary Barcode (EA)     | 条件必填 | EA 级主条码（UPC/EAN/GTIN）；多数仓必需 |
| Additional Barcodes (EA) | 可选   | EA 级附加条码（新旧并存/多市场）          |
| Case / Carton Barcode    | 可选   | 箱级条码（如 ITF-14）              |
| Pallet Barcode           | 可选   | 托盘条码（如 SSCC）                |

---

### ⑦ 仓库分配与组织（Warehouse Assignment）

👉 指定货主、仓库、库区约束等建档上下文

| 字段                      | 必填度  | 说明                  |
| ----------------------- | ---- | ------------------- |
| Owner Code              | 条件必填 | 货主/客户编码（多货主场景必填）    |
| Facility / Warehouse ID | 条件必填 | 目标仓/园区 ID（多仓时对每仓建档） |
| Inbound Preference      | 可选   | 优先入库仓/库区            |
| Outbound Preference     | 可选   | 优先拣选仓/库区            |

---

### ⑧ WMS 同步与状态（WMS Sync & Status）

👉 创建/更新商品时，自动构造 Item Master 负载并同步到 WMS

| 字段                  | 必填度  | 说明                                |
| ------------------- | ---- | --------------------------------- |
| Sync on Create      | \*必选 | 新建商品即向 WMS 建档（开启/关闭）              |
| Sync on Update      | \*必选 | 计量/包装/条码/批次/序列/存储属性变更即增量更新        |
| Preview Payload     | 可选   | 同步前查看将发送给 WMS 的 JSON 预览           |
| Idempotency Key     | 系统生成 | 幂等键（如 Owner+Facility+SKU+Version） |
| Sync Status         | 系统生成 | Pending / Success / Failed（含错误原因） |
| Retry Policy        | 可选   | 失败重试（指数退避/手动重推）                   |
| Last Synced At / By | 系统生成 | 最近同步时间/操作者                        |
| WMS Item ID         | 系统回写 | 成功后回写 WMS 侧的物料/商品 ID              |
| Per-Facility Status | 系统生成 | 多仓并行建档时按仓显示独立状态                   |

### ✅ 页面交互顺序（推荐）

**库存管理 → 批次与效期 → 序列号管理 → 存储与作业属性 → 包装与仓储计量 → 条码与扫描 → 仓库分配与组织 → WMS 同步与状态**
