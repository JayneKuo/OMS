

# 🛃 Compliance & Customs — 功能分区与字段（最终版）

---

### ① Customs Basics

👉 清关报关的最小必填信息

| Field (English)       | 必填度  | 中文说明                           |
| --------------------- | ---- | ------------------------------ |
| Chinese Name          | \*必填 | 中文申报品名                         |
| English Name          | \*必填 | 英文申报品名（跨境必需）                   |
| Declared Purpose      | 可选   | 产品用途说明                         |
| Material              | 可选   | 主要材质（Cotton / Plastic / Metal） |
| HS Code (Global)      | \*必填 | 默认税则号（6 位或以上）                  |
| Declared Value        | \*必填 | 海关申报单价，含币种                     |
| Declared Unit         | \*必填 | 申报计量单位（EA / PCS / KG 等）        |
| Country of Origin     | \*必填 | 原产国/制造国                        |
| Brand                 | 条件必填 | 特定类目必填（玩具、服装等）                 |
| Model / Specification | 可选   | 产品型号/款式                        |

### ② Hazmat & Special Goods

👉 危险品、锂电池、特殊品类字段（按需显隐）

| Field (English)          | 必填度  | 中文说明                   |
| ------------------------ | ---- | ---------------------- |
| Hazmat Flag              | \*必选 | 是否危险品（Yes/No）          |
| UN Number                | 条件必填 | 危险品编号（例：UN3481）        |
| DG Class / Packing Group | 条件必填 | 危险品类别/包装组              |
| Battery Type             | 条件必填 | 电池类型：Li-ion / Li-metal |
| Battery Wh / Content     | 条件必填 | 电池瓦时 / 锂含量             |
| MSDS / SDS               | 条件必填 | 上传安全数据表（近 3 年内有效）      |
| Ingredients / Allergen   | 动态必填 | 食品：成分与过敏源              |
| Nutrition Facts          | 动态必填 | 食品：营养成分表               |
| FDA Registration         | 动态必填 | 食品/保健品 FDA 注册号         |
| CPSIA / ASTM             | 动态必填 | 儿童产品：合规标准              |
| FCC / RoHS / REACH       | 动态必填 | 电子产品：合规认证              |

---

### ③ Tariff & Market Profiles

👉 税则与市场差异化配置

| Field (English)  | 必填度  | 中文说明                             |
| ---------------- | ---- | -------------------------------- |
| Market / Country | \*必填 | 国家或市场（US/EU/UK/CA 等）             |
| HS Code (Market) | 条件必填 | 市场覆盖的税则号（覆盖 Global）              |
| Duty Rate        | 条件必填 | 关税税率 %                           |
| Tax Type         | 条件必填 | VAT / GST / Import Duty / Excise |
| Currency         | 条件必填 | 税则币种（USD/EUR/CNY 等）              |
| Remark           | 可选   | 特殊说明（如免税条款）                      |

---

### ④ Certificates & Attachments

👉 证书与合规附件管理

| Field (English)      | 必填度  | 中文说明                                     |
| -------------------- | ---- | ---------------------------------------- |
| Certificate Type     | \*必选 | CE / FCC / FDA / UL / ISO / MSDS / CPC 等 |
| Certificate No.      | 条件必填 | 证书编号                                     |
| Issuing Body         | 条件必填 | 发证机构                                     |
| Issue Date           | 条件必填 | 签发日期                                     |
| Expiry Date          | 条件必填 | 到期日期（用于提醒）                               |
| Coverage             | 可选   | 适用范围（SKU/批次/类目）                          |
| Certificate File     | \*必填 | 上传证书 PDF/ZIP                             |
| Supporting Documents | 可选   | 商业发票、装箱单、COO 证、说明书等                      |

---

### ⑤ Review & Expiry

👉 审核流转与到期提醒

| Field (English)      | 必填度  | 中文说明                                  |
| -------------------- | ---- | ------------------------------------- |
| Compliance Status    | 系统生成 | Draft / Pending / Approved / Rejected |
| Reviewer / Notes     | 条件必填 | 审核人及意见                                |
| Expiry Alerts        | \*必选 | 到期提醒（30/60/90 天）                      |
| Change Log           | 系统生成 | 字段修改历史（人、时间、前后值）                      |
| Revalidation Trigger | 系统生成 | 法规/渠道变更触发复审                           |

---

### ⑥ Integration & Sync

👉 渠道/报关对接

| Field (English) | 必填度  | 中文说明                       |
| --------------- | ---- | -------------------------- |
| Broker Export   | 可选   | 导出报关资料（CSV/JSON）           |
| Channel Sync    | 可选   | 同步至电商渠道（如 Amazon 合规字段）     |
| Preflight Check | 系统生成 | 上架/清关前检查（缺失项提示）            |
| Sync Status     | 系统生成 | Pending / Success / Failed |
| Last Sync / By  | 系统生成 | 最近同步时间与操作者                 |
