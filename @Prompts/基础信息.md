
🗂️ 基础信息（Basic Info）模块 — 功能分区与字段

① 基本资料（General Info）
👉 商品最小必填身份信息
字段	必填度	说明
Product Name	*必填	商品名称，前台可见，审核敏感
SKU	*必填	商家唯一库存编号
Parent SKU	条件必填	仅在多变体商品时使用，用于分组
Product Type	*必选	Physical / Digital / Bundle
Category	*必选	平台类目，驱动属性模板
Brand	条件必填	部分类目必填，电商平台敏感字段
Status	*必选	Draft / Active / Inactive
Is Sample	可选	是否为样品，开关按钮

② 图片与媒体（Images & Media）
👉 用于商品前台展示和平台审核
字段	必填度	说明
Main Image	*必填	至少 1 张，白底、无水印
Additional Images	可选	附图，支持多张排序
Video	可选	≤60s 演示视频

③ 描述与属性（Description & Attributes）
👉 基于类目动态显示的商品属性
字段	必填度	说明
Description	可选	长文本描述（富文本）
Bullet Points	可选	卖点，3–5 条
Category Attributes	类目驱动	根据所选类目动态加载（例：服装=尺码/颜色，食品=成分/营养表，电子=电压/功率）

④ 物流信息（Logistics Info）
👉 商品最小单位的计量、重量与尺寸
字段	必填度	说明
Primary UOM	*必选	主计量单位（EA, KG, LB, Pack…）
Additional UOMs	可选	辅助计量单位（Case, Pallet），含换算关系
Net Weight	*必填	商品净重
Gross Weight	可选	毛重（含包装）
Dimensions (L×W×H)	*必填	商品尺寸，cm/inch

⑤ 包装层级（Packaging Levels）
👉 仓储维度的物理包装关系
层级	必填度	说明
Unit (EA)	固定=1	最小售卖单位
Inner Pack	可选	1 内包装 = N EA
Master Carton	可选	1 外箱 = N EA / Inner Pack
Carton Dimensions/Weight	可选	外箱尺寸/重量

⑥ 变体管理（Variants）
👉 多规格商品的父子关系
字段	必填度	说明
Enable Variants	*必选	Yes / No
Variant Dimensions	条件必填	最多 3 个：Color / Size / Material / Style…
Variant Options	条件必填	具体选项，如 Color=Red/Blue
Child SKU Table	系统生成	包含：SKU（必填）、Parent SKU、Barcode、Variant Title、Variant Image、Weight/Dimensions、Status

⑦ 条码（Barcode）
👉 商品物理识别标识
字段	必填度	说明
Primary Barcode (UPC/EAN/GTIN/ISBN)	条件必填	大多数电商/零售平台必填
Additional Barcodes	可选	同一 SKU 多条码（新旧包装共存）
Custom Code	可选	商家内部自定义编码
