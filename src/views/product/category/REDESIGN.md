# Category Management - Level Navigation Redesign

## 设计理念

从传统的**树状表格展示**改为**层级导航式交互**，参考类似京东、淘宝的多级分类管理界面。

## 核心特性

### 1. **层级导航布局** 📐

### 2. **交互流程** 🔄

#### 初始状态
- 显示 Level 1 面板
- 显示所有一级分类列表

#### 选择一级分类
```
点击 "Bags" 
↓
- Level 1 面板中 "Bags" 高亮
- Level 2 面板出现，显示 "Bags" 下的所有二级分类
- 面包屑更新: All Categories > Bags
```

#### 选择二级分类
```
点击 "Women Bags"
↓
- Level 2 面板中 "Women Bags" 高亮
- Level 3 面板出现，显示所有三级分类
- 面包屑更新: All Categories > Bags > Women Bags
```

#### 选择叶子节点
```
点击最末级分类（无子分类）
↓
- 对应面板项目高亮（绿色左边框）
- 下方详情面板展开
- 显示完整信息和 Mapping 按钮
```

### 3. **搜索功能** 🔍

每个级别独立搜索：
- Level 1 搜索框：只搜索一级分类
- Level 2 搜索框：只搜索当前选中一级下的二级分类
- Level 3 搜索框：只搜索当前选中二级下的三级分类
- Level 4 搜索框：只搜索当前选中三级下的四级分类

**实时过滤**，无需点击搜索按钮

### 4. **新增分类逻辑** ➕

#### 对话框设计
```
┌─────────────────────────────────────┐
│ Add Category                         │
├─────────────────────────────────────┤
│ Category Type:                       │
│ ○ Parent Category (New L1)           │
│ ● Child Category (Under: Bags)       │
│                                      │
│ Parent: All Categories > Bags        │
│                                      │
│ Category Name: *                     │
│ [_________________________]          │
│                                      │
│ Category Code: *                     │
│ [_________________________] [Generate]│
│                                      │
│ Status: [Active ●──○ Inactive]      │
│                                      │
│         [Cancel]  [Confirm]          │
└─────────────────────────────────────┘
```

#### 新增规则
1. **Parent Category**: 创建新的一级分类
   - 无需选择父级
   - Level = 1

2. **Child Category**: 在当前选中节点下创建子分类
   - 必须先选中父级分类
   - 如果当前在 L1，则创建 L2
   - 如果当前在 L2，则创建 L3
   - 如果当前在 L3，则创建 L4
   - 如果当前在 L4，禁用（最大4级）

### 5. **面包屑导航** 🍞

```
All Categories > Bags > Women Bags > Handbags
    ↓           ↓        ↓            ↓
  点击返回    点击返回  点击返回    当前位置
```

- 点击任意层级返回该层级
- 自动清除后续级别的选择
- 自动调整显示的面板数量

### 6. **叶子节点识别** 🍃

**叶子节点特征**：
- 没有 children 或 children.length === 0
- 左侧绿色边框标识
- 点击后显示详情面板
- 显示 "Manage Mappings" 按钮

**非叶子节点特征**：
- 有子分类
- 显示子分类数量标签（如 "10 sub"）
- 右侧显示箭头图标
- 点击后展开下一级

### 7. **详情面板** 📝

只在选中**叶子节点**时显示：

#### 基本信息
- 分类名称
- 分类代码
- 所属层级
- 更新时间
- 状态标签

#### 平台映射
显示每个平台的映射状态：
```
Shein:    Category Name #12345
Amazon:   Not mapped
Shopify:  Product Category #67890
```

#### 操作按钮
- **Manage Mappings**: 管理平台映射（主要操作）
- **Edit**: 编辑分类信息
- **Delete**: 删除分类
- **Status Switch**: 启用/禁用开关

## 优势分析

### vs 树状表格

| 对比项 | 树状表格 | 层级导航 |
|--------|----------|----------|
| **视觉清晰度** | 复杂，嵌套层级多时难以阅读 | 清晰，每级独立显示 |
| **操作便捷性** | 需要展开/收起节点 | 直接点击选择 |
| **搜索精度** | 全局搜索，结果混杂 | 分级搜索，精确定位 |
| **信息密度** | 低，大量空白 | 高，并列显示 |
| **层级理解** | 需要通过缩进判断 | 通过面板位置直观理解 |
| **叶子节点识别** | 不明显 | 绿色边框清晰标识 |
| **Mapping操作** | 每行都显示，干扰视线 | 只在选中叶子节点时显示 |

### 交互优势

1. **渐进式展开**
   - 不会一次性加载所有数据
   - 按需显示下级分类
   - 减少视觉负担

2. **上下文清晰**
   - 面包屑显示完整路径
   - 当前选中项高亮
   - 层级关系一目了然

3. **操作聚焦**
   - 详情面板只显示叶子节点
   - Mapping 按钮不干扰浏览
   - 减少误操作

4. **空间利用**
   - 横向并列展示多级
   - 每级独立滚动
   - 不浪费垂直空间

## 响应式适配

### 桌面端 (>1400px)
- 并排显示 4 个面板
- 每个面板宽度均等

### 平板端 (768px - 1400px)
- 并排显示 3 个面板
- 第 4 级使用抽屉/模态框

### 移动端 (<768px)
- 只显示当前级别面板
- 使用左右滑动切换级别
- 面包屑改为下拉菜单

## 性能优化

1. **懒加载**
   - 只渲染当前可见的面板
   - 未选中的级别不加载数据

2. **虚拟滚动**
   - 分类数量超过 100 时启用
   - 只渲染可见区域的列表项

3. **搜索防抖**
   - 300ms 延迟执行搜索
   - 避免频繁过滤操作

4. **数据缓存**
   - 已加载的级别数据缓存
   - 返回上级时直接使用缓存

## 快捷键支持

| 快捷键 | 功能 |
|--------|------|
| `←` | 返回上一级 |
| `→` | 进入下一级（如果已选中） |
| `↑` / `↓` | 在当前面板中上下选择 |
| `Enter` | 选中当前项 |
| `Ctrl+F` | 聚焦当前级别搜索框 |
| `Ctrl+N` | 新增分类 |
| `Esc` | 清除选择/关闭详情面板 |

## 总结

这个新设计将分类管理从"表格视图"转变为"导航视图"：

✅ **更直观** - 层级关系清晰可见  
✅ **更高效** - 快速定位目标分类  
✅ **更聚焦** - 操作按钮只在需要时显示  
✅ **更灵活** - 支持多种交互方式  
✅ **更专业** - 符合大型电商平台的管理习惯

适合管理**大量多级分类**的场景！
