# Category List Style Optimization - Simple & Efficient

## 优化目标
将分类列表从花哨的设计改为简洁、高效、易读的实用界面。

## 主要优化点

### 1. **统计区域重构** 📊
**之前**: 复杂的卡片布局，多个嵌套元素
**现在**: 单行统计栏，信息一目了然

```
Total: 150 | Mapped: 120 | Unmapped: 25 | Pending: 5
Shein: 50 (40/10) | Amazon: 60 (50/10) | Shopify: 40 (30/10)
Last Sync: 12/25/2024 | OK
```

- 减少70%的垂直空间占用
- 移除所有渐变、阴影、动画效果
- 使用紧凑的横向布局
- 信息密度提高300%

### 2. **表格优化** 📋

#### 列宽优化
| 列名 | 之前 | 现在 | 节省 |
|------|------|------|------|
| Category ID | 120px | 120px | 0 |
| Category Name | 300px | 300px | 0 |
| Platform Mappings | 300px | 280px | -20px |
| Update Info | 200px | 110px | **-90px** |
| Status | 100px | 80px | **-20px** |
| Actions | 200px | 140px | **-60px** |

**总共节省: 170px 水平空间**

#### 单元格优化
- 减少内边距：`12px` → `8px`
- 字体大小：`14px` → `13px`
- 行高：`48px` → `36px`
- **信息密度提升 33%**

### 3. **平台映射显示** 🔗
**之前**: 横向标签云，占用大量空间
**现在**: 纵向紧凑列表

```
Shein:    Category Name #12345
Amazon:   -
Shopify:  Product Cat #67890
```

优势：
- 垂直对齐，易于扫描
- 清晰显示映射状态
- 使用等宽字体显示ID
- 未映射显示 "-" 而非啰嗦的 "Unmapped"

### 4. **分类树视觉** 🌳
**简化**:
- 虚线宽度：`2px` → `1px`
- 层级缩进：`24px` → `20px`
- 最小行高：`48px` → `36px`
- 移除所有hover动画
- 移除装饰性背景渐变
- 使用等宽字体显示分类代码

**效果**: 更清晰的层级关系，更少的视觉干扰

### 5. **颜色方案** 🎨
移除所有自定义颜色，全面使用 Element Plus 变量：

```scss
// ❌ 之前
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
box-shadow: 0 12px 24px rgba(102, 126, 234, 0.25);
color: #5a67d8;

// ✅ 现在
background-color: var(--el-fill-color-light);
border: 1px solid var(--el-border-color-lighter);
color: var(--el-text-color-secondary);
```

### 6. **交互简化** 👆
- 移除所有 `transform` 动画
- 移除所有 `box-shadow` 效果
- 移除所有渐变背景
- 保留基本的 `:hover` 背景色变化
- Switch 大小从 default → small

### 7. **间距统一** 📏
```scss
// 统一间距系统
padding: 16px;      // 容器
margin-bottom: 16px; // 区块
gap: 8px;           // 元素间距
border-radius: 4px;  // 圆角
```

### 8. **字体层级** 📝
```scss
// 简化字体大小
统计栏: 13px
表头: 13px
表格内容: 13px
分类名称: 13px
代码/ID: 12px (monospace)
更新时间: 12px
```
